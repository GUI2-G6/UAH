# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| beta (beta.uahapp.com) | ❌ Not Yet Active |
| dev (dev.uahapp.com) | ✅ Active (team only) |
| prod (uahapp.com) | ❌ Not Yet Active |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

If you discover a security issue — including but not limited to authentication bypasses, exposed credentials, injection vulnerabilities, or unauthorized data access — please report it privately:

**Email:** security@uahapp.com  
**Subject line:** `[SECURITY] Brief description`

Include in your report:
- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any suggested fixes if you have them

We will acknowledge your report within 48 hours and keep you updated as we investigate and resolve the issue.

## Scope

The following are in scope for security reports:
- `beta.uahapp.com`
- `dev.uahapp.com`
- `uahapp.com`
- The UAH GitHub repository and any deployed code within it

## What We Ask

- Give us reasonable time to investigate and fix before any public disclosure
- Do not access, modify, or delete user data during testing
- Do not perform denial of service testing against our infrastructure

## Known Limitations

UAH is currently an academic project in active development. Some features are incomplete or in prototype state. We appreciate responsible disclosure and will do our best to address legitimate findings promptly.
