# UAH Browser Extension: Easy Install Guide (Chrome)

This guide is for non-technical users.

You do **not** install the `.zip` directly in Chrome.
You must unzip it first, then load the extracted folder.

## Before you start

- Use Google Chrome on desktop (Windows, Mac, or Linux).
- Download this file from UAH:
  - `uah-browser-extension-alpha.zip`

## Step-by-step (simple)

1. Download `uah-browser-extension-alpha.zip` from the UAH website.
2. Find the zip file in your Downloads folder.
3. Right-click it and choose **Extract All** (or unzip with your normal unzip tool).
4. Open Chrome and go to: `chrome://extensions`
5. Turn on **Developer mode** (toggle in the top-right).
6. Click **Load unpacked**.
7. Select the **extracted folder** (the unzipped one), then click Select/Open.
8. You should now see the UAH extension in your list.

## If Chrome says "Manifest file is missing"

You probably selected the wrong folder.

Try again and select the extracted folder that contains `manifest.json`.

## If you downloaded a newer alpha zip

1. Unzip the new file.
2. Go to `chrome://extensions`.
3. Remove the old UAH extension entry (or use Reload if you prefer).
4. Click **Load unpacked** and select the new extracted folder.

## Notes

- This is an alpha build and may change often.
- Keep the extracted folder on your computer; Chrome uses it as the extension source.
